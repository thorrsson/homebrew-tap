# thorrsson/homebrew-tap

Homebrew casks for thorrsson's macOS apps.

```sh
brew install --cask thorrsson/tap/unifi-desktop
```

If Homebrew refuses to load a cask from an untrusted tap, run `brew trust thorrsson/tap` once.

| Cask | App |
|---|---|
| `unifi-desktop` | [UniFi Desktop](https://github.com/thorrsson/osx-unifi) |

Casks are updated automatically by each app's release workflow; don't edit them by hand.
